## 1. Core principle

Every EHB industry sits on the same **shared trust stack**:

```
PSS   — identity & trust
CRB   — verification & skill
DMO   — control & earnings (Mode: FAST / BALANCED / STRICT / CRITICAL)
STL   — ranking & trust score
Wallet + Blockchain  — money & ledger
```

No industry is a silo. Every industry reuses the same plumbing. DMO mode determines approval speed and risk tolerance.

## 5. DMO Mode Mapping — Decision Speed & Risk Profile

| Mode | Industries | Approval Speed | Risk Level | Formula |
|------|-----------|---|---|---|
| **FAST** | GSM, FBS, LDS, PTS, BCS, ELS | < 2 hours | Low | DMO auto-approves if Activity > 70 + Behavior > 75 |
| **BALANCED** | HPS, OBS, ERS, EPS, EAS, ITS, SOT, HMS, EHB_TUBE, ATS, FWS, MAS, GES, EHB_MUSIC, WES, TCS, EDS, GSS, RRS, CMS | 1-3 days | Medium | DMO requires manager review, AI suggests, human approves |
| **STRICT** | WMS, OLS, CNS, RES, LSM, HCS, MFS | 3-7 days | High | DMO requires senior manager + inspector field check |
| **CRITICAL** | FIN, INS, SCS, EFS | 7-14 days | Very High | DMO requires director + legal review + compliance audit |

## 6. Industry → STL Level Correlation

**Baseline:** Most industries (L1-L2) accept users at any STL level.

**Medium-risk (L2-L3):** ERS, RES, LSM, MFS require L2+ before listing services.

**High-risk (L3-L4):** OLS, FIN, INS, SCS require L3+ before listing services.

**Critical (L4+):** WMS requires L4+ (healthcare professional verification).

---

## 7. Final flow

```
User → PSS Verification → Choose Industry → CRB Exam (if needed) → 
Create Profile → DMO Approval (via mode: FAST/BALANCED/STRICT/CRITICAL) → 
STL Assignment → Service Listing → Earnings & Blockchain Hash
```

Every industry follows this exact pipeline. The industry code determines:
- Which CRB exams/certifications are required
- Which DMO mode applies
- Which product categories show in the catalogue
- Minimum STL level to list

---

## 8. Industry Codes — Consistency Rules

1. **All uppercase:** GSM, WMS, HPS, OBS, OLS, etc.
2. **Max 5 chars:** (except compound like `EHB_TUBE`, `EHB_MUSIC`)
3. **No ambiguity:** Each code maps to exactly one industry name, globally.
4. **Never reused:** Retired codes are archived; never reassigned.
