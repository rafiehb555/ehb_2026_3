# EHB · Value Proposition

> **Status:** Canonical v1.0 · 2026-04-30
> **Question this answers:** "Why EHB instead of Fiverr / Amazon / Upwork / Binance / TaskRabbit?"

## The 1-sentence pitch

> **"EHB is the world's first multi-industry platform where every user, seller, product, and service has a portable on-chain Service Trust Level (STL) — so trust earned in one industry compounds across all 38+, with token-locked skin in the game preventing fraud."**

## For each user type — why EHB beats alternatives

### 🛒 Buyer

| Pain on existing platforms | EHB solution |
|---|---|
| Each platform has its own ratings — no portability | STL travels across 38+ industries |
| Fake reviews from low-trust accounts | Reviewer's STL weights every review |
| Refunds are platform-discretion | EHBGC escrow + 100% project-value protection |
| No clear who's the actual seller vs reseller | MIN-chain shows Owner → Company → Seller → Product |
| Buyer abuse (false complaints) hurts honest sellers | Buyer Trust Score separate from STL |

### 🏪 Seller

| Pain on existing platforms | EHB solution |
|---|---|
| Reputation locked to single platform | Take your STL anywhere on EHB |
| Unfair platform-wide algorithm changes | Transparent STL formula (58 gold-master tests protected) |
| Account suspended without recourse | DMO 4-mode ladder (warn → 24h → 7d → ban) + appeal mechanism |
| Race to the bottom on price | Higher STL = lower fees + higher search ranking + premium-tier earnings |
| Capital requirements stuck on platform | EHBGC lock yields 4-6% APY while you sell |

### 🛠 Service Provider (lawyer / doctor / tutor)

| Pain on existing platforms | EHB solution |
|---|---|
| Fiverr/Upwork: no verified credentials | CRB exam + multimedia proof + on-chain certificate |
| Earnings capped by platform commission | AI Marketplace: per-session fees, no commission on direct hire |
| No insurance on disputes | Lock + insurance alternative |
| Cross-discipline impossible (e.g., lawyer → consultant) | STL portable across OLS, HPS, JPS |

### 🏛 Franchisee

| Pain on franchise systems | EHB solution |
|---|---|
| Single-brand locked (KFC, McDonalds) | EHB franchise = territory rights across 38 industries |
| Static royalty share | Sub L1-L10 ladder · 40/25/20/15 split among Sub/Master/Corporate/Country |
| No technology stack provided | Full EHB platform + DMO console included |
| No global buyer base | Direct access to EHB's user pool |

### 🛵 Rider

| Pain on existing platforms | EHB solution |
|---|---|
| Race-to-bottom delivery rates | Earnings cap by STL: L5 $50/day, L10 unlimited |
| One bad customer ruins rating | Reviewer's Buyer Trust Score weighs reviews |
| No upward mobility | Rider STL → Inspector → Franchise (legal-cross-paths) |

## Network-effect moat

Every user/seller/product joining EHB:
- Strengthens the trust graph (more reputation data)
- Makes fraud harder (more cluster signals for AI)
- Increases franchise revenue (more orders for territory)
- Locks more EHBGC (deflationary pressure)

This compounds. Year-over-year defensibility increases — hard to clone.
