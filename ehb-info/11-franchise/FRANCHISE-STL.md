# EHB · Franchise STL

> **Status:** Canonical v1.0 · 2026-04-30

## Master rule

> **Franchise STL caps at L8 (alone).** Franchise is the ONLY role that uniquely caps at L8 — combined with PSS+CRB+DMO can reach L10.

Source: `3-departments/STL.md §3` + `EHB-USER-TYPES.md §6 Franchisee`.

## STL contribution to franchise

Franchise STL composite:

```
Franchise STL = MIN(
   Personal STL of franchisee,
   Performance metrics STL,
   Compliance STL,
   Local trust STL
)
```

Then capped at L8 alone, but boosted via:
- + PSS verified L8+
- + CRB Inspector cert
- + DMO clean record
- → can reach L10 SUPREME

## STL effects on franchise

| Franchise STL | Effects |
|---|---|
| L1-L3 | Probationary · DMO close watch · limited verification authority |
| L4-L5 | Standard operations · can run sub-L5 verifications |
| L6-L7 | Trusted · vouching authority · industry premium tiers |
| L8 (cap alone) | VIP franchise · cross-tier authority · master eligibility |
| L9-L10 | (combined) Elite · territory expansion · founder pipeline |

## STL gates for franchisees

| Activity | Min Franchise STL |
|---|:---:|
| Operate Sub L1-L3 | L4 |
| Operate Sub L4-L7 | L6 |
| Operate Sub L8-L10 | L7 |
| Apply for Master | L7 |
| Operate Master | L8 |
| Apply for Country | L8 + Council vote |
| Operate Country | L9-L10 (combined) |

## STL boost franchise gives to others

A franchisee can give STL boosts:

- Sub L5+ vouching new users → +1 STL boost (vouchee)
- Master vouching Sub → +1 STL boost (sub)
- Country vouching Master → +1 STL boost (master)

Vouching carries co-risk: if vouchee fails, vouchor STL drops too.

## Franchise endorsement on product cards

When a franchise endorses a seller in their territory:

- Product card shows: "🏛 Endorsed by Karachi R1 Sub L5 Franchise ✓"
- Buyer trust signal +
- Search ranking boost
- Insurance auto-included (per franchise tier)

## STL drop scenarios

Franchise STL drops when:

- Refill missed → -1 per miss
- Complaint upheld against franchise → -2
- Fraud detected in vouched user → -3 + slash
- Quarterly KPI miss → -1
- Inspector caught faking reports → -5 + investigation

## STL recovery for franchise

- 90-day clean record: +1 STL
- 6-month perfect performance: tier promotion eligible
- Re-train + re-certify after major incident
- Founder pardon (rare, for systemic exception)
