**Goals:**

---

## 2. Franchise Hierarchy (5 levels — FINAL)

```
LEVEL 1 → COUNTRY FRANCHISE        (top — 1 per country)
LEVEL 2 → MASTER FRANCHISE         (region / city)
LEVEL 3 → CORPORATE FRANCHISE      (company-level)
LEVEL 4 → SUB FRANCHISE            (small business / shop)
LEVEL 5 → MICRO FRANCHISE          (individual / freelancer) ← NEW · growth engine
```

---

## 3. Per-level details

### 🌍 Level 1 — COUNTRY FRANCHISE (top)

```
Role:
- Pure country ka control
- All industries + all cities

Rights:
- Sub franchises assign kar sakta hai
- Revenue share control
- Local policies adjust

Revenue Sources:
- % from all transactions in country
- Franchise fees
- Subscription + services

Control:
- Direct EHB HQ se linked
```

**Country rules:**
- 1 country = 1 main franchise (exclusive)
- Backup: Co-partner allowed (max 2)

### 🏢 Level 2 — MASTER FRANCHISE

```
Role:
- City / Region control
Example: Punjab / Dubai / Riyadh region

Rights:
- Corporate franchises assign kare
- Local operations manage kare

Revenue:
- % from sub + corporate
```

### 🏬 Level 3 — CORPORATE FRANCHISE

```
Role:
- Company level control
Example:
- Hospital chain
- Logistics company
- Education institute

Rights:
- Own services list kare
- Employees onboard kare
```

### 🧩 Level 4 — SUB FRANCHISE

```
Role:
- Small business / shop level
Example:
- Local shop
- Freelancer group

Rights:
- Direct customer deal
```

### ⚡ Level 5 — MICRO FRANCHISE (growth engine)

```
Role:
- Individual / small earners
Example:
- Delivery boy
- Freelancer
- Affiliate seller

Earning:
- Per task / commission

Entry:
- Easy onboarding (no heavy investment)
```

**Why critical:** Micro = the **growth engine** of EHB. Removes capital barrier for individuals · feeds Sub/Corporate tiers via promotion.

## 4. System Flow

```
EHB HQ
  ↓
Country Franchise
  ↓
Master Franchise
  ↓
Corporate Franchise
  ↓
Sub Franchise
  ↓
Micro Franchise
  ↓
User / Customer
```

## 5. Revenue Flow

```
Customer Payment
  ↓
Escrow (Wallet)
  ↓
Split:
Micro → Sub → Corporate → Master → Country → EHB HQ
```

Bottom-up settlement: Micro keeps biggest share (delivers the work), each upper tier takes commission for territory + governance.

## 6. Control System

```
EHB HQ:
- Global rules
- AI + blockchain control

Country:
- Local law + pricing tweak

Master:
- Region performance

Corporate:
- Service quality

Sub:
- Execution

Micro:
- Task delivery
```

## 10. Entry requirements

| Level | Requirement |
|---|---|
| Country | High capital ($5M+) + team |
| Master | Medium-high capital ($100K-$500K) |
| Corporate | Registered company + capital |
| Sub | Small business + EHBGC lock |
| Micro | Individual · easy onboarding · minimal lock |

## 11. Scaling logic (self-growth ecosystem)

```
Micro grows →
becomes Sub →
becomes Corporate →
becomes Master
```

**This is the heart of EHB's growth model:** start small, prove yourself, climb tiers organically.
