## Core idea

> **Har industry ka apna franchise ecosystem hoga · sab same CORE ENGINE (AI + Wallet + Blockchain) use karenge.**

Each industry runs the same 5-tier hierarchy:

```
Country → Master → Corporate → Sub → Micro
```

## Critical rules

```
❌ Same user multiple franchise levels pe conflict create nahi karega
❌ Direct bypass allowed nahi
✅ Sab kuch system flow se hoga
```

This means:
1. A user cannot be both Sub and Master in same territory
2. Direct user-to-Micro bypass (skipping franchise) not allowed
3. All revenue flows through canonical 5-tier split

---

## Cross-industry membership

A single franchisee can hold positions in multiple industries:

- Example: A Pakistani entrepreneur can be Sub L5 in GSM (e-commerce) + Sub L4 in OLS (legal) + Country in OBS (book store) — different industries, different tiers
- BUT: cannot hold conflicting tiers in SAME industry in SAME territory
