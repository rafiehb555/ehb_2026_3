## Country franchise rules per country

### Country exclusivity
- **1 country = 1 Country franchise** (exclusive)
- Backup: max 2 co-partners allowed (founder approval)
- Country franchisee has territory monopoly + obligations

### Capital requirements
- Phase-1 countries: $5M-$15M
- Phase-2 countries: $10M-$30M
- Phase-3 countries: $30M-$50M (higher entry due to market complexity)

### Compliance setup per country

| Country | Key compliance |
|---|---|
| PK | NADRA + SECP + SBP + FBR |
| AE | UAE Central Bank + Emirates ID |
| SA | SAMA + Iqama |
| TR | TCMB + Turkish KYC |
| MY | Bank Negara + MyKad |
| QA, KW, OM | Local Central Banks + ID systems |
| ID | OJK + KTP |
| EG | CBE + National ID |
| UK | FCA + GDPR |
| US | SEC + FinCEN + state-by-state |
| CA | OSFI + provincial |
| DE, FR | BaFin/AMF + GDPR + MiCA |
| CN | PBOC + unique regulatory regime |
| IN | RBI + Aadhaar + PAN |

### Localization per country

- Language: country's primary + English (mandatory)
- Currency: local + USD-eq display
- Payment gateways: local providers
- Industries: phase-gated rollout
- Marketing: localized messaging
- Customer support: local-language team

### Country franchise responsibilities

1. Set up local legal entity
2. Engage compliance officer per country
3. Recruit Master franchises in major cities
4. Coordinate with local KYC vendors
5. Government relations
6. Country-level marketing strategy
7. Direct line to EHB HQ
8. Quarterly country-level reports
