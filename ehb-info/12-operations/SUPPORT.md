# EHB · Customer Support

> **Status:** Canonical v1.0 · 2026-04-30
> **Note:** Master spec — `2-phases/SUPPORT-SYSTEM.md` has tier breakdown.

## Support channels

| Channel | Use case | Response SLA |
|---|---|---|
| AI chat bot | First-line · 70%+ deflection | Instant |
| Live chat | Complex issues | <5 min |
| Email | Asynchronous · documentation | <2h |
| Phone | Critical · regional | <30 min |
| In-person (franchise) | High-stakes · L8+ users | Same day |

## STL-prioritized queue

| User STL | Priority | Wait time |
|---|---|---|
| L9-L10 | VIP | Instant |
| L7-L8 | High | <30 min |
| L4-L6 | Standard | <2h |
| L1-L3 | AI-first, escalate if needed | <5h |

## Support topics (by frequency)

1. Account / login issues (35%)
2. Order tracking / status (20%)
3. Payment / wallet questions (15%)
4. KYC / verification queries (10%)
5. Refund / dispute (route to dispute flow) (8%)
6. Bug reports (5%)
7. Feature requests (3%)
8. Compliance questions (2%)
9. Other (2%)

## AI bot capabilities

- Answers common Qs from FAQ
- Knows user's order history, current STL
- Can perform actions: cancel order, request refund, update profile
- STL-aware: gives different responses to L1 vs L8 user
- Escalates complex / sensitive queries

## Multi-language support

Phase-1: English + Urdu + Arabic
Phase-2: + Hindi + French + Spanish + Mandarin
Phase-3: + 20+ languages via AI

## Support staff requirements

- PSS L4+ (verified employees)
- Trained on EHB systems (40-hour course)
- Industry knowledge (rotation per industry)
- Empathy + de-escalation training
- Performance KPIs: CSAT, resolution time, deflection rate
