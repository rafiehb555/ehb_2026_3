# EHB · Content Moderation

> **Status:** Canonical v1.0 · 2026-04-30
> **Note:** Detailed in `2-phases/MODERATION.md`. This is ops-level summary.

## What gets moderated

- Listings (products, services, jobs)
- Reviews + complaints
- Profile content (bio, avatar)
- Messages (P2P + group)
- Multimedia uploads (photos, videos)
- Forum / community (Phase-3+)

## 3-tier moderation

```
AI auto-screen → Human reviewer (DMO Staff) → DMO Council (final)
```

## AI screening capabilities

- Profanity / abuse detection
- Spam / link patterns
- AI-generated content flag
- Stock-image identification
- Scam pattern recognition (price too low, hidden contact)
- Counterfeit detection (image authenticity)
- Hate speech detection (multi-language)

## Industry-specific moderation rules

- WMS: medical claims need evidence
- OLS: legal advice needs jurisdiction disclosure
- FIN: investment claims regulated
- EDS: educational content quality
- EHB_TUBE: community guidelines
