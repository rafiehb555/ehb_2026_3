## 7. Reset old data — safe approach

Founder asked: "sub sa pehle all old data ko reset karain"

**Recommendation: NOT a hard reset.** Instead:

1. Keep all current files (they have value)
2. For each file, audit against 11-section template
3. Add missing sections where empty
4. Mark obsolete sections as "ARCHIVED" or move to `9-archive/`
5. Bump versions, log changelogs
6. Result = same files but fully completed — no data loss

A hard reset would lose 4 weeks of canonical work. Layered fix is safer + faster.

---

## 8. Master file approach — final answer to founder

Founder asked: "kia ham 1 file man kam krain gay or os file say data others all file man jay ga"

**Final approach:**

- ❌ NOT 1 mega-file (would be 10,000+ lines, unmanageable)
- ✅ **Layered files with auto-flow:**
  - **`MASTER-DASHBOARD.md`** (single founder view)
  - **Per-topic canonical files** (1 topic = 1 file)
  - **Auto-discovery (`_settings/`)** connects them
  - **Auto-update rules** propagate changes
  - **Founder edits ONE topic at a time** in its file (Claude does the editing)

What founder reads: ONE file (MASTER-DASHBOARD.md)
What Claude manages: ALL files
What founder writes: TEXT only

This is cleaner than single-file, faster than copy-paste, and prevents drift.
