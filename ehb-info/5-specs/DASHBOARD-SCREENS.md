# EHB · Dashboard Screens Catalog

> **Status:** Canonical v1.0 · 2026-04-30

## Per role — required dashboards

### 🛒 Buyer
- Home / browse · Cart · Orders · Wishlist · Profile · Wallet · Notifications · Reviews

### 🏪 Seller / Service Provider
- Sales overview · Listings · Orders · Earnings · Reviews · CRB exams · Refill schedule · STL · Wallet · Lock status

### 🛵 Rider
- Dashboard (current jobs) · Earnings · Schedule · Reviews · STL · Lock status

### 🔎 Inspector
- Inspection queue · Schedule · Reports · Earnings · STL

### 🌐 Franchisee
- Territory overview · Sub-applications · Refill mgmt · Revenue · Health · STL

### 🧑‍💼 Employer (jobs)
- Posted jobs · Applicants · Hires · Spend · STL

### 📄 Job Seeker
- Profile · Applications · Skills (CRB) · Earnings · STL

### 🏛 Admin (DMO)
- See `4-flows/ADMIN-PANEL-DATA.md` for all 12 admin panels

## Common dashboard widgets

- STL hero (current level + journey stepper)
- KPI cards (sparklines)
- Activity feed (recent events)
- Notifications panel
- Quick actions
- Earnings chart
- Wallet balance + lock status
- Refill timer
- Pending reviews / actions

## Industry-specific dashboards

For each of 38 industries:
- Custom widgets (e.g., medical = patient queue, legal = case files)
- Industry-specific KPIs
- Compliance reminders

## Mobile-first responsive

- All dashboards work on 380px (mobile) → 1440px (desktop)
- Bottom nav on mobile
- Sidebar on desktop
- Touch targets ≥ 44px
