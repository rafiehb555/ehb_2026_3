# EHB · User Panels Catalog

> **Status:** Canonical v1.0 · 2026-04-30

## Public panels (no login)

- Landing page
- About / Mission
- How it works
- Industries grid
- Trust system explainer
- Pricing
- Sign up / Sign in

## Authenticated panels

- Dashboard (role-specific — see `DASHBOARD-SCREENS.md`)
- Profile (PSS status, edit)
- Settings (notifications, language, currency)
- Wallet (balance, transactions, lock, yield)
- Notifications (real-time)
- Help / Support

## Role-conditional panels

- Seller: Listings, Earnings, CRB exams
- Service: Profile setup per industry, Bookings
- Buyer: Cart, Orders, Wishlist, Reviews
- Rider: Active job, Schedule
- Franchisee: Territory map, Sub-list, Refills
- Inspector: Queue, Reports
- Admin: 12 admin panels (see `ADMIN-PANEL-DATA.md`)

## Industry-conditional panels

- WMS: Patient queue, prescription management
- OLS: Case files, contract templates
- HPS: Course catalog, learner management
- ERS: Property listings, valuations
- FIN: Portfolio, transaction history
- (etc. for each of 38)

## Cross-cutting features

- Search bar (global)
- Quick filters (industry, STL, location)
- Switch role (if user has multiple)
- Switch language (Urdu/EN/AR/HI)
- Switch currency
- Dark mode toggle
