# Referral Program — EHB Platform

> **Owner:** Growth + Affiliate
> **Note:** Distinct from Affiliate (formal partner). Referral = user-to-user organic.

## Mechanics

### Referrer rewards
- $5 (or local equivalent in EHBGC) when referee completes first transaction
- +1 STL temporary boost for 30 days (caps at L4)
- Bonus: +$10 if referee reaches L4 within 90 days

### Referee rewards
- $5 sign-up credit (locked until first transaction)
- Free STL onboarding coach (AI-driven)

### Caps
- Max 100 referrals / referrer / year (anti-abuse)
- Max $500 / referrer / year via referrals
- Velocity limits: max 5 / day

## Anti-Abuse
- Same device fingerprint → flagged
- Same payment method → flagged
- Same address (verified) → flagged
- Sudden spikes → DMO review
- Slash referrer if fake referees detected

## Tracking
- Unique referral code per user (8-char)
- UTM tracking on link
- Attribution: 30-day window, last-touch
- Anchored to chain on payout

## UI Flow
1. User clicks "Invite friends"
2. Sees their code + share buttons (WhatsApp, SMS, email, X)
3. Friend signs up via link → automatic attribution
4. Both notified at each milestone (sign-up, first txn, L4)

## Geographies
- Fully active in Phase 1 countries (PK, AE, SA, TR, MY)
- Compliance check before activating each new country
- USA / EU: careful — unlawful inducement laws
