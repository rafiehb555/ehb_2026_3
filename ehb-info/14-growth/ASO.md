# App Store Optimization (ASO) — EHB Mobile

> **Owner:** Marketing + Mobile Team
> **Targets:** App Store (iOS) + Google Play (Android)

## App Listing Strategy

### Title
- iOS: 30 chars max — *"EHB — Trusted Marketplace"*
- Android: 50 chars — *"EHB Technologies: 38 Industries One Trusted App"*

### Subtitle / Short Description
*"Verified pros, secure payments, instant trust score (STL)."*

### Long Description
Open with what + who-for. Then trust angle (Polkadot, STL). Then 38 industries. Then country list. Then call to action.

### Keywords (iOS — 100-char field)
trust,marketplace,verified,services,goods,franchise,STL,polkadot,escrow,WMS,OLS,GSM,jobs

### Visuals
- Icon: EHB logo, simple, recognizable at 24px
- Screenshots (6 per device family):
  1. Hero — "Your trust score, visualized"
  2. Industry picker — "38 industries, one app"
  3. Service search — "Verified pros only"
  4. Order tracker — "Escrow + chain anchor"
  5. Earnings — "Sellers earn more with high STL"
  6. Franchise — "Own a piece of EHB"
- Video preview: 15s overview

## Per-Country Localization
Translate listing for each launch country. Use local screenshots (currency, language). Use local app reviews.

## Reviews
- In-app prompt to review after first successful order (NPS-style)
- Respond to every public review within 24h
- Address negative reviews proactively
- Track ratings as KPI (target: 4.5+)

## Update Cadence
- Major release: every 2 weeks
- Hotfix: as needed
- Each release with changelog visible in app
- A/B test screenshots quarterly

## ASO Tools
- AppFollow / Sensor Tower / data.ai for keyword tracking
- Apple Search Ads / Google Ads for paid validation
