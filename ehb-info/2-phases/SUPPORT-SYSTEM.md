# EHB · Support System

> **Status:** Canonical v1.0 · 2026-04-30

## Support tiers

| Tier | Channel | Response SLA |
|---|---|---|
| Tier 0 (self-service) | FAQ + AI bot | Instant |
| Tier 1 (chat) | Live chat | <5 min |
| Tier 2 (specialist) | Escalation | <2h |
| Tier 3 (DMO) | Senior DMO | <24h |
| Tier 4 (founder) | Critical only | <72h |

## STL-based support priority

| User STL | Priority |
|---|---|
| L9-L10 | VIP queue (instant) |
| L7-L8 | High priority (<1h) |
| L4-L6 | Standard (<5h) |
| L1-L3 | AI-first, escalate if needed |

## Support topics

- Account / login issues
- KYC / verification questions
- Order / refund / dispute (route to dispute flow)
- Wallet / payment / lock
- Technical bugs
- Feature requests
- Compliance questions
- Industry-specific help

- Answers 70% of common questions
- STL-aware responses
- Knows user's order history, current STL
- Escalates complex / sensitive to human
